## 信息架构建议（两句）

1. **左侧合成一个「阿蝉」侧栏**：HUD（身份 / 七变量 / 勿扰 / 楼梯）+ 背包 + 行为日志纵向排成一栏（上：我；中：背包；下：日志），右侧合成一个「小镇」侧栏：世界信息 + 小地图 + 导播六人状态 + 聊天小卡——两栏常驻、中间留给画面；导播三态按钮和时间控制收进小镇栏顶部一行。
2. **弹出的只留三类**：QQ 手机（居中）、聊天室（居中偏下、可收成图标）、门禁 / 交互 toast（顶部居中一条，敲门 / 开门 / 回话都在这一条里按状态变）；登录页改成像素风标题画面（同一套九宫格框 + 两个按钮）。其余（楼梯、勿扰、找别人聊）都做成侧栏里的小按钮，不再各自浮一块。
